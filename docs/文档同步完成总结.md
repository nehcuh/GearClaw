### 4.5 `agent.system_prompt`

覆盖 Agent 的默认系统提示词。支持多行字符串（YAML `|-` 语法）。

默认提示词包含：
- Agent 角色定位
- 自主扩展能力指导（MCP/Skills 搜索与安装）
- 工作原则（主动扩展、自主决策、清晰说明、持续学习）

示例：
```toml
[agent]
system_prompt = |-
  你是一个专业的 Rust 开发助手。
  专注于代码审查和性能优化。
```

**注意**: 修改提示词可能影响 Agent 的自主扩展行为。
```

**影响**: ✅ 用户了解如何自定义 Agent 系统提示词
