## 💡 如何运行演示

### 前提条件

1. ✅ 已完成项目构建：`cargo build`
2. ✅ 已初始化配置：`cargo run -p gearclaw_cli -- init`
3. ✅ MCP 服务器可用（如需要）

### 运行步骤

```bash
# 1. 阅读演示文档
less docs/demos/02-gmail-automation.md

# 2. 运行演示脚本
./scripts/utils/gmail_automation.sh

# 3. 查看结果报告
cat docs/demos/03-gmail-success-report.md
```

### 命名规范

- 文件名: `<数字>-<主题>.md` (如 `04-new-feature.md`)
- 标题清晰: 一句话说明演示内容
- 包含验证: 必须有实际运行结果
- 可复现: 提供完整步骤
